# معلّمي

منصة عربية لمعلم مادة لغتي الخالدة في المرحلة المتوسطة، تشمل إدارة الفصول والطلاب، المهام والتسليمات، التخطيط الأسبوعي، بنك الأسئلة، التحصيل الدراسي، الحضور، مهارات نافس، الخطط العلاجية، أنماط التعلم، وبنك الملفات.

## النشر

المشروع صفحة ثابتة جاهزة للنشر على GitHub Pages من الفرع الرئيسي ومجلد الجذر.

> تحتاج وظائف تسجيل الدخول والحفظ ورفع الملفات إلى إعداد Supabase المرتبط بالمشروع.
