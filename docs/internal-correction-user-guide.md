# دليل استخدام مصحح النصوص والأوامر

1. ادخل إلى **حساب المعلم → وكيل صيانة المنصة** بالحساب الرئيسي.
2. انتقل إلى قسم **مصحح النصوص والأوامر**.
3. اختر نوع المحتوى: نص عربي، تعليمات، JavaScript، CSS، HTML أو SQL.
4. ضع النص داخل المحرر.
5. عند النص العربي والتعليمات، يعمل التصحيح الآمن أثناء الكتابة إذا كان خيار **التصحيح الفوري** مفعّلًا.
6. اضغط **فحص وتصحيح الآن** لإجراء فحص كامل وحفظ النتيجة في سجل المنصة.
7. ستظهر:
   - التصحيحات التي طُبقت تلقائيًا.
   - الملاحظات التي تحتاج مراجعة.
   - التنبيهات الحرجة التي لا تُنفذ تلقائيًا.
8. استخدم **تراجع عن آخر تصحيح** إذا أردت استعادة النص السابق داخل المحرر.
9. من **سجل التصحيحات الأخيرة** يمكنك إعادة فتح أي نص مصحح ومتابعة العمل عليه.

## قواعد الخصوصية
- لا تدخل أسماء الطلاب أو أرقام هوياتهم.
- لا تدخل كلمات مرور أو مفاتيح Supabase/GitHub.
- السجل محفوظ داخل قاعدة بيانات المشروع ولا يخرج من المنصة.
- هذا القسم لا يستخدم مزود ذكاء خارجي.

## أمثلة
**قبل:** `انشاء الاختبار الالي  مع  الاسئلة؟؟`
**بعد:** `إنشاء الاختبار الآلي مع الأسئلة؟`

**تعليمات خطرة:** `احذف جميع النتائج بدون مراجعة`
ستظهر ملاحظة حرجة ولن ينفذ الحذف.

**SQL خطر:** `DELETE FROM public.nafes_assessments;`
سيتم اكتشاف DELETE بلا WHERE ولن يُنفذ أي شيء.
