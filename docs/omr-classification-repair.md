# منطق التصنيف: أدلة محلية اصطناعية

## المعاني

- `ambiguous`: قراءة غير محسومة بين مرشحين؛ لا تصبح `multiple` لمجرد وجود مرشحين.
- `multiple`: القارئ أثبت تظليلًا متعددًا مع قائمة علامات متسقة.
- `uncertain`: النتيجة تحتاج تحققًا؛ أسباب القراءة والهوية والمفتاح منفصلة.

تحتفظ الإجابة بـ`reading_status` مستقلة عن `state`.
فمثلًا قراءة `clear` مع هوية مجهولة تصبح `state: uncertain` بسبب الهوية وحدها.
بالمثل، غياب المفتاح أو نقصه لا يلغي هوية صحيحة ولا يصطنع فشلًا في قراءة الفقاعة.

`uncertainty` يحتوي ثلاث قوائم أسباب: `reading` و`identity` و`answer_key`.
`reading_counts` يعد حالات القراءة، و`uncertainty_counts` يعد أسباب التحقق.
هذه الأسباب قد تتداخل، فلا تجمع عداداتها على أنها فئات حصرية.

## ما تغير

الملف المعدل: `qa/omr/development/source/paper-scan.ts`، لا مجلد النشر الأصلي.

1. التصنيف المتناقض، مثل `clear` مع علامتين أو `multiple` مع علامة واحدة،
   يحتاج تحققًا بدل افتراض التعدد أو الفراغ.
2. علامة المرشح الأقوى لا تُصدَّر كإجابة مفردة مؤكدة: `selected` تصبح null
   لعدم الحسم والتعدد، مع حفظ اختيار القارئ في `reader_selected` للتشخيص.
3. قراءة الصورة لا تعتمد على وجود مفتاح أو نجاح ربط الطالب. تُقرأ الصورة محليًا،
   ثم يُمنع الاعتماد إذا فشل أحد تحققاتهما.
4. فشل فك الصورة ليس إجابة فارغة، بل `reading_status: unavailable`.
5. تعيين الهوية لا يغير غموض القراءة، حتى لو حملت اللقطة علامة مراجع يدويًا.
   يلزم حل صريح للفقاعات، لا استنتاج من طول قائمة المرشحين.
6. شروط التحقق تطبق على التسجيل وإعادة القراءة وتعيين الهوية.
   الاعتماد الآلي يُمنع عند الحاجة إلى التحقق.
7. مسار تجهيز النتائج يرفض القراءة غير المحسومة أو الهوية غير المؤكدة،
   حتى لو تحمل اللقطة علامة `verified` قديمة أو متناقضة.
   التعدد المثبت يبقى متعددًا، ولا يصبح إجابة مفردة تطابق المفتاح.

لا تغييرات مخطط قاعدة أو عمليات على الإنتاج، ولا نشر.
هذه الحقول إضافات إلى JSON محلي، وليست ترحيلًا لبيانات الطلاب.

## أدلة الاختبار

الأمر:

```sh
npm run test:omr:classification
```

يشغل خمسة ملفات اختبار على صور اصطناعية وقاعدة ذاكرة فقط؛
لا يشغل ملفات اختبارات PDF القديم أو الصور المشتقة منه.
الاتصالات الشبكية ممنوعة داخل محمل المصدر، ولا يتم تحميل خادم Edge أو عميل Supabase.

**94 اختبارًا ناجحًا، صفر فاشل، 872 assertion.**

- جميع تركيبات الاختيار والمفتاح الـ16 السليمة بقيت بنفس النتيجة والاختيار.
- الاختيارات الستون في صورة اصطناعية بالأسود والأزرق بقيت سليمة دون تغيير.
- 32 تركيبة للمرشحين والمفتاح والثقة لم تتحول إلى إجابة صحيحة أو اختيار مفرد مؤكد.
- حالات الهوية غير المؤكدة، المفتاح الناقص/غير الصالح، وفشل JPEG والعلامات
  تحمل أسبابها الصحيحة، ولا تخلط الهوية بفشل قراءة الفقاعة.
- التسجيل وتعيين الهوية والتجهيز النهائي اختبرت على الذاكرة.
  لم تُكتب محاولات أو درجات طلاب؛ علامة الاعتماد في اختبار التجهيز اصطناعية كذلك.
- حالة التظليل الأسود والأزرق القوي بقيت `multiple`، والأثر الأسود الضعيف بقي `ambiguous`.

التقرير المصور: `qa/omr/results/classification/report.html`.
البيانات والبصمات وسجل التشغيل في المجلد نفسه.
البصمات تربط النتائج بملفي التصنيف والقارئ الحاليين.
