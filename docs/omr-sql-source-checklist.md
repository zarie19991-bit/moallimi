# مصدر SQL الأصلي المطلوب لإغلاق الاختبارات الأربع

## الاستخراج

الملف: `qa/omr/export/manual-review-metadata-readonly.sql`.

ينفّذه المالك في مشروع Supabase الأصلي ويحفظ قيمة
`manual_review_source_metadata` كملف JSON أو نص. لم ينفذه Replit Agent ولم يتصل
بالإنتاج. الاستعلام SELECT واحد على pg_catalog؛ لا يقرأ صفوف الطلاب أو
الدرجات أو الصور أو مخازن الأسرار أو إعدادات الاتصال. يُرجع إصدار PostgreSQL
فقط لتحديد توافق بيئة الاختبار، ولا يقرأ مفاتيح أو قيم إعدادات أخرى.

**مهم:** أجسام الوظائف والقيم الافتراضية تعريفات مصدرية، لكنها قد تحتوي على أسرار
مضمّنة في مشروع ما. يراجع المالك الناتج قبل مشاركته ويزيل أي أسرار أو بيانات شخصية
مضمّنة، ويوضح الأجزاء التي حجبها. لا ترسل مفاتيح أو connection strings أو .env.
ليس مطلوبًا تصدير بيانات صفوف أو نسخة احتياطية بيانات.
يحجب الاستعلام أجسام وظائف أو قيمًا افتراضية تظهر فيها مؤشرات اعتماد مشبوهة،
ويضع علامة withheld_for_review. هذا مرشح تحفظي وليس ضمانًا لكشف كل سر، وقد يحجب
نصًا آمنًا لمجرد ذكر اسم مفتاح. يوفّر المالك المصدر المنقّح لهذه الأجزاء بدون
إرسال قيم أسرار؛ الحجب لا يُعتبر تعريفًا مكتملًا للاختبار.

## الجداول

الجداول الخمسة التي حددها المالك:

- nafes_scan_sheets
- nafes_scan_sessions
- nafes_scan_answer_edits
- nafes_scan_identity_edits
- nafes_scan_alerts

يدخل في الاستخراج أيضًا nafes_paper_reviews وnafes_assessment_attempts، لأن
مصدر Edge الموجود يشير إليهما في سياق الجلسة والمحاولات السابقة. هذه مراجع مصدرية،
لا افتراض بوجود مخطط محدد. يُرجع الاستعلام أسماء الجداول غير الموجودة بدل إنشاء بدائل.

لكل جدول: الأعمدة، أنواعها، NULL، القيم الافتراضية، identity/generated،
القيود بما فيها FK والتأجيل، الفهارس بما فيها partial/expression/unique،
RLS وسياساته، المحفزات وحالة تفعيلها وأجسام وظائفها.

تُصدَّر أسماء وقيم أنواع enum المرتبطة بالأعمدة وتعريفات sequences المملوكة فقط؛
لا تُقرأ قيم last_value أو is_called. إذا كانت هناك domains أو composite types أو
جداول FK أو دوال مساعدة إضافية، يلزم مصدرها الأصلي بعد تحديدها من الناتج.
الاستعلام ليس pg_dump كاملًا ولا ضمانًا لاكتمال كل التبعيات؛ لا يُعاد بناء البدائل بالتخمين.

## الوظائف

يكتشف الاستعلام الوظائف الموجودة بالفعل بالبادئة nafes_scan_ ويصدر توقيع كل
overload وجسمه ومالكه وACL وSECURITY DEFINER. لا يضيف معاملًا أو وظيفة.

المراجع المباشرة في Edge الحالي التي يجب مطابقتها مع الناتج:

- nafes_scan_register
- nafes_scan_edit_answer
- nafes_scan_assign_identity
- nafes_scan_verify_current
- nafes_scan_finish

نافذ الحذف nafes_scan_delete_corrections موجود كمرجع مصدر لكنه ليس بديلًا للحفظ،
ولن تُنفذ عمليات حذف إنتاجية. أي مساعد تستدعيه الوظائف يجب فحص مصدره الأصلي،
خصوصًا التحقق من المراجع/الصلاحيات أو قفل النسخة أو منع الاعتماد المكرر.

## خطة الاختبارات الأربعة

| الاختبار المعلّق | المصدر اللازم | دليل الإغلاق المطلوب |
|---|---|---|
| حفظ التعديل وسببه ذريًا | edit_answer، جدول answer_edits، القيود والمحفزات | سبب محفوظ، before/after ورقم النسخة والمراجع مطابقون؛ rollback كامل عند الفشل؛ عدم ترقية ambiguous بمجرد الحفظ |
| رفض غير المحسوم والنسخة القديمة | verify_current، sheets، الصلاحيات والأقفال | رفض ambiguous/uncertain/الأدلة المتناقضة؛ عدم رفع verified أو تغيير الدرجات؛ منع سباق النسخ |
| إنهاء الدفعة وتدقيق الهوية | finish، assign_identity، sessions، identity_edits | الدفعة المعلّقة مرفوضة؛ الاختيارات ثابتة بعد تغيير الهوية؛ سبب وتاريخ التعديل محفوظان؛ إعادة المعالجة لا تمحو المراجعة حتى مع المحفزات |
| التسجيل/الاعتماد المتكرر والمتزامن | register، verify_current، finish، فهارس sheets/alerts/attempts | إعادة الطلب لا تنتج ورقة/اعتمادًا ثانيًا؛ تكرار الصورة/الهوية مكشوف؛ طلبان متزامنان لا يتجاوزان القيود |

اختبار المنطق البشري يحتاج توقيع SQL الحقيقي لمعرفة موضع السبب، لا معامل p_reason
مفترض. وجود اسم وظيفة أو فهرس فقط لا يثبت صحة التنفيذ.

## بعد وصول المصدر

1. تحقق من اكتمال المصدر وتبعياته قبل تشغيله.
2. افحص الاتصال الخارجي، SECURITY DEFINER، والآثار الجانبية؛ لا تُنقل إعدادات
   الإنتاج أو أسراره. تُستخدم قاعدة محلية مؤقتة لا تطبيق Replit ولا Supabase الأصلي.
3. شغّل نفس التعريفات الأصلية مع بيانات اصطناعية وعزل الوصول الخارجي.
4. سجّل نتائج الأساس والفشل، ثم أصلح النسخة المحلية فقط وأعد اختبار الحالات.
5. أغلق كل اختبار بدليل SQL فعلي، لا نجاح كائنات JavaScript.

حتى وصول المصدر، الحالات الأربع **معلّقة بسبب نقص المصدر وليست نجاحًا أو فشلًا SQL**.
لا تنتقل هذه المرحلة إلى أي إصلاح آخر، ولا تُنشر التغييرات أو تُعدّل درجات الإنتاج.
