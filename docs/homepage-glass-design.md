# تصميم الصفحة الرئيسية الزجاجية — منصة معلّمي

## 1) هدف التعديل
- إظهار شعار معلّمي كاملًا دون قص في الشريط الجانبي وعلى الجوال.
- إضافة هوية زجاجية مع تموجات خلفية خفيفة دون مكتبات حركة خارجية.
- المحافظة على وضوح النصوص وسهولة الاستخدام.
- إبقاء التغيير محصورًا في `body.page-dashboard` حتى لا يتداخل مع صفحات الطباعة أو التحليل.

## 2) أسباب مشكلة الشعار
1. تعدد قواعد CSS الخاصة بـ `.brand` بين `styles.css` و`stitch-platform-theme.css` و`homepage.css` و`moallimi-brand.css`.
2. اختلاف الارتفاع والحشو بين الحاويات.
3. عدم وجود شعار ظاهر مباشرة على الهاتف عند كون القائمة الجانبية مغلقة.
4. عدم تثبيت أبعاد HTML للصورة في الصفحة الرئيسية.

## 3) الحل
- أبعاد ثابتة للصورة: `360×120`.
- `object-fit: contain`.
- `overflow: visible` على حاويات الهوية.
- رفع الحد الأدنى لارتفاع منطقة الهوية في الشريط الجانبي.
- إضافة نسخة شعار صغيرة داخل الشريط العلوي على الهاتف.
- preload للشعار و favicon للعلامة.

## 4) نظام Glassmorphism
لا توجد أي مكتبة JS للحركة. التأثير مبني على:
- `backdrop-filter`
- أسطح بيضاء شبه شفافة
- حدود شفافة
- ظلال منخفضة الكثافة
- ثلاث طبقات تموج CSS فقط
- تحريك `transform` فقط لتقليل تكلفة إعادة الرسم
- `prefers-reduced-motion` لتعطيل الحركة لمن يفضّل ذلك

## 6) نقاط التوافق
- Chrome / Edge / Safari الحديثة: Glass كامل.
- المتصفحات بدون `backdrop-filter`: fallback أبيض شبه معتم.
- الهاتف: تخفيف blur وإخفاء الموجة الثالثة.
- تقليل الحركة: جميع التموجات تتوقف.

## 7) ميزانية الأداء
التغيير يضيف ملف CSS فقط، بلا صور خلفية وبلا مكتبات.
هدف التنفيذ:
- عدم إضافة JavaScript خاص بالحركة.
- عدم إضافة طلبات صور جديدة عدا الشعار الموجود أصلًا.
- تحميل CSS الإضافي بحجم صغير.
- استخدام transforms بدل تحريك top/left.
- تخفيف blur على الشاشات الصغيرة.

## 8) خطة اختبار
| الاختبار | الحالة المستهدفة |
|---|---|
| 1440×900 | الشعار كامل والبطاقات متوازنة |
| 1024×768 | لا قص للشعار ولا overflow |
| 768×1024 | القائمة الجانبية قابلة للفتح |
| 390×844 | شعار صغير ظاهر في topbar |
| Reduced Motion | لا حركة للتموجات |
| No backdrop-filter | fallback واضح ومقروء |
| Keyboard | زر القائمة يحتفظ بـ aria-expanded |
