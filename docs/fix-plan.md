# حزمة إصلاح منصة معلّمي

هذه الحزمة تعالج الملاحظات التالية:

- تحكم فتح/إغلاق مهارات نافس لكل فصل.
- لوحة يومية مبنية على مهام المعلم الفعلية.
- ملف طالب شامل.
- كشف درجات عملي وإدخال جماعي.
- ربط تصحيح المهمة ببند التحصيل الدراسي.
- الحضور والمشاركة من شاشة واحدة.
- اقتراح خطط علاجية من نتائج نافس المنخفضة.
- دخول الطالب مباشرة إلى المهمة/الاستبانة/اختبار نافس عبر الرابط أو QR.
- تنظيف بنية الواجهة إلى ملفات HTML/CSS/JS مستقلة.
- معالجة تحذيرات الأمان الخاصة بالاستبانات العامة.
