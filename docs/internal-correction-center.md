# تقرير وحدة التصحيح الداخلي — منصة معلّمي

## الهدف
وحدة داخلية لتصحيح النصوص والتعليمات والأكواد داخل المنصة دون تصدير المحتوى أو إرسال النص إلى مزود خارجي.

## المكونات
- `platform-auto-correct.js`: محرك التصحيح المحلي في المتصفح.
- `maintenance-agent.html/js/css`: واجهة مركز التصحيح داخل وكيل الصيانة.
- `maintenance-agent` Edge Function: حفظ سجل التصحيحات واسترجاعه للحساب الرئيسي.
- `maintenance_agent_corrections`: جدول تاريخ التصحيحات داخل Supabase.

## أنماط الفحص
1. نص عربي: إملاء، ترقيم، مسافات، أخطاء شائعة مؤكدة.
2. تعليمات تشغيلية: نفس التصحيح النصي + اكتشاف أوامر الحذف الواسعة وتجاوز التحقق والتعديل المباشر على main.
3. JavaScript: توازن الأقواس/الاقتباس، eval، innerHTML الديناميكي، تخزين المفاتيح الحساسة في localStorage.
4. CSS: الأقواس، الإفراط في !important، قواعد A4 التي تسبب الفراغات، page-break الإجباري.
5. HTML: أخطاء العرض الحرفية مثل \\n، وصور بلا alt.
6. SQL: DELETE/UPDATE بلا WHERE، TRUNCATE، DROP، تعطيل RLS، SECURITY DEFINER وGRANT ALL.

## سياسة التنفيذ
- التصحيحات منخفضة المخاطر فقط تُطبق تلقائيًا داخل نفس حقل المحرر.
- الملاحظات المنطقية والأمنية لا تُنفذ تلقائيًا.
- كل تشغيل يدوي يحفظ سجلًا داخل مشروع المنصة.
- لا تُرسل البيانات إلى OpenAI أو أي API خارجي من هذا القسم.
- الحقل مخصص للنصوص والأوامر ولا يقبل أرقام هوية/إقامة من 10 أرقام في أوضاع النص والتعليمات.
- يمنع حفظ الأسرار والمفاتيح التي تشبه service_role أو مفاتيح طويلة.

## نموذج البيانات
`maintenance_agent_corrections`:
- owner_id
- mode
- source_label
- original_text
- corrected_text
- issues JSON
- auto_fix_count
- review_count
- status
- created_at / applied_at

RLS مفعّل، ولا يملك anon أو authenticated صلاحية مباشرة على الجدول. الوصول يتم عبر Edge Function بالحساب الرئيسي.

## التحقق المنفذ
- تحقق صياغي لملفي JavaScript الرئيسيين بعد التعديل.
- نشر Edge Function الإصدار 10 بنجاح.
- اختبار إدخال/قراءة داخل معاملة بدور service_role ثم rollback.
- تحقق أن سجل الاختبار لم يبق بعد rollback.
- تحقق من أن RLS مفعّل وأن anon/authenticated بلا SELECT مباشر.

## حدود مقصودة
المصحح لا يعيد كتابة منطق برمجي أو SQL خطِر تلقائيًا. الهدف منع الأخطاء المؤكدة وتسليط الضوء على ما يحتاج قرارًا هندسيًا، لا استبدال مراجعة الكود.
