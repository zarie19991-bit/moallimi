# تقرير تنفيذ تطوير منصة «معلّمي»

تاريخ التنفيذ: 2026-10-03
النطاق: منصة GitHub Pages `zarie19991-bit/moallimi` + قاعدة Supabase المرتبطة.

## 1. الملخص التنفيذي

تم تحويل المراجعة إلى خطة تنفيذ عملية بثلاث طبقات: إصلاحات فورية آمنة، تحسينات هيكلية مجدولة، وضوابط تشغيل وصيانة مستمرة. نفذت المرحلة الأولى الآمنة على الواجهة دون لمس البيانات الحساسة أو حذف أي سجلات.

| المحور | الإجراء المنفذ | الأثر |
|---|---|---|
| الهوية والشعار | إضافة preload للشعار و favicon عبر `teacher-preboot.js` وتوحيد CSS في `moallimi-brand.css` | تقليل احتمال ظهور صفحة بلا هوية أثناء التحقق أو بطء تحميل الشعار |
| تجربة التحميل | إظهار الشعار داخل شاشة preboot بدل شاشة نصية فقط | يحافظ على العلامة التجارية في أول ثانية دخول |
| التوحيد البصري | تحديث قواعد عرض الشعار والفواصل والأحجام عبر مكوّن هوية موحد | تقليل اختلاف الشعار بين الصفحات |
| التوثيق | إنتاج خطة تطوير وتشغيل وصيانة قابلة للتنفيذ | يجعل المتابعة قابلة للقياس والمراجعة |

قيود متعمدة: لم يتم تنفيذ تغييرات RLS أو حذف/تعديل قاعدة البيانات مباشرة؛ لأن ذلك قد يعطل المنصة أو يكرر مشكلة فقد البيانات. جرى توثيق خطة الأمان وSQL المقترح للمراجعة قبل التطبيق.

```text
  ├─ الاختبارات الإلكترونية
  │   ├─ اختباراتي
  │   ├─ إنشاء/تعديل
  │   └─ تحليل النتائج

```

## 4. مقتطفات الكود المنفذة

### 4.1 تحميل الشعار والـfavicon مبكرًا

```js
const LOGO='moallimi-logo-ui.png?v=20261003-brand2';
const ICON='moallimi-brand-icon-v2.webp';

function ensureBrandHead(){
  if(!document.querySelector('link[data-moallimi-logo-preload]')){
    const preload=document.createElement('link');
    preload.rel='preload';
    preload.as='image';
    preload.href=LOGO;
    preload.setAttribute('fetchpriority','high');
    preload.dataset.moallimiLogoPreload='1';
    document.head.appendChild(preload);
  }
}
```

### 4.2 شاشة تحقق بهوية واضحة

## 6. مؤشرات نجاح مقترحة

| المؤشر | الوضع المستهدف |
|---|---:|
| ظهور الشعار عند أول تحميل | 100% من صفحات الشاشة |
| JS أولي في الصفحة الرئيسة | أقل من 200KB خام |
| عدد ملفات CSS في التحليل | 5 أو أقل |
| اختبارات GitHub Actions الحرجة | نجاح قبل أي Deploy |
| عمليات حذف عامة | 0 مسار إنتاجي |
| قابلية طباعة A4 | اختبار بصري آلي لكل نموذج رئيسي |

## 7. التوصية النهائية

لا يُعاد بناء المنصة من الصفر. الأفضل هو برنامج تحسين تدريجي مضبوط: تثبيت الهوية، فصل المسارات، تقليل التعقيد، ثم الأمان والأداء والاختبارات الآلية. هذا يحافظ على قيمة العمل الحالي ويقلل خطر التعطيل.
