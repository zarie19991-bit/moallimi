# تصدير التعريفات الأصلية لإكمال اختبار OMR

## التنفيذ مرة واحدة

1. افتح `qa/omr/export/manual-review-metadata-readonly.sql` في محرر ملفات Replit.
2. انسخ **الملف كاملًا**، بما فيه `WITH RECURSIVE` حتى الفاصلة المنقوطة الأخيرة.
3. افتح SQL Editor في مشروع Supabase الأصلي، والصق الاستعلام في نافذة جديدة ثم اضغط Run.
4. الناتج صف واحد وعمود واحد باسم `manual_review_source_metadata`.
5. صدّر **النتيجة** كملف CSV من قائمة تنزيل النتائج، أو انسخ قيمة الخلية كاملة واحفظها كملف JSON بترميز UTF-8.
6. راجع الملف للتأكد من عدم وجود أسرار ثابتة داخل أجسام SQL، ثم ارفع **ملف النتيجة الواحد** في محادثة Replit. لا تحتاج إلى مفتاح التشفير أو مفتاح Supabase.

الاستعلام SELECT واحد للقراءة فقط. يقرأ كتالوج PostgreSQL وتعريفات الكائنات وصلاحياتها؛ لا يقرأ صفوف المستخدمين أو الطلاب أو المحاولات، ولا يستدعي وظائف التطبيق، ولا يجلب كلمات مرور الأدوار أو القيم الحالية للتسلسلات.

## المحتوى

- العلاقات الثلاث `auth.users` و`public.moallimi_classes` و`public.nafes_analysis_exclusion_audit` مطلوبة صراحة، إضافة إلى جداول المسح والمحاولات والتبعيات المعروفة.
- الوظائف الخمس الناقصة والوظائف التسع السابقة مطلوبة صراحة، مع جميع overloads الموجودة وأذونات EXECUTE الفعلية.
- أعمدة الجداول وقيمها الافتراضية وقيودها وFK وفهارسها ومحفزاتها وRLS وACL؛ وصلاحيات جداول نواة المسح الست.
- تبعيات FK ووظائف المحفزات وتعابير القيم الافتراضية وCHECK وRLS؛ وتبعيات الوظائف المكتشفة من الكتالوج وأجسام SQL.
- صلاحيات المخططات والتسلسلات وملكيتها، والأنواع enum/domain، وسمات الأدوار وعضويتها دون كلمات مرور.
- `effective_acl` يفك الصلاحيات الافتراضية عندما يكون ACL الخام NULL؛ لا يعني NULL انعدام الصلاحيات.
- `missing_requested_tables` و`missing_requested_functions` يحددان الأسماء المطلوبة التي لم تُعثر عليها، دون إنشاء بدائل.

## احتياطات ضرورية

- يحجب الاستعلام تعريفات وقيمًا افتراضية وتعابير تحمل علامات أسرار، ويضع إشارات حجب للمراجعة. الكشف احتياطي، **وليس ضمانًا لاكتشاف أي سر مكتوب حرفيًا بشكل غير معروف**؛ مراجعة صاحب المشروع قبل المشاركة مطلوبة.
- لا تحذف الأجزاء المحجوبة أو تتجاوزها أثناء الاستيراد. تحتاج مراجعة نسخة أصلية منقّحة لا تغيّر منطقها.
- SQL الديناميكي أو المراجع المركبة داخل النصوص قد تحتاج مراجعة يدوية؛ لا توجد وسيلة كتالوجية تضمن اكتشاف جميع تبعيات PL/pgSQL تلقائيًا.
- لا ترفع الناتج إلى GitHub العام ولا تُدرجه في حزمة نشر. يستخدم محليًا فقط، خارج شجرة المستودع.
- ملف CSV ذو خلية JSON مقتبسة مقبول؛ لا تعدّل الاقتباسات أو تقسّم الناتج إلى عدة رسائل.

## التحقق المحلي

`python3 qa/omr/sql/export-metadata-tests.py`

اجتاز الاستعلام 49 تحققًا على كتالوج اصطناعي في PostgreSQL 17.6، ومنها تنفيذ SELECT نفسه داخل معاملة READ ONLY، وتسلسل التبعيات، والصلاحيات، وحجب قيم تحمل علامات أسرار، وعدم ظهور قيم صفوف الاختبار. هذه ليست اختبارات قبول نشر المحاولات أو التراجع الإداري. تلك تُستكمل بعد وصول التعريفات الأصلية.
