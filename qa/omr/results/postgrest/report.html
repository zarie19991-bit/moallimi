الإصلاح المثبت

مسار API كان يحفظ الدرجة دون رمزي المخرج والمؤشر في الأسئلة؛ فتظل النتائج التابعة فارغة. أضيف الحقلان من FRAMEWORK الموثوق. قبل الإصلاح: صفر نتائج تابعة؛ بعده: نتيجة مرتبطة بالمحاولة، ويُعاد تجميعها بعد التراجع.
