# معلّمي: نتيجة فحص التعريفات المتبقية

## الحكم

**غير جاهز للنشر.** لا يوجد مصدر محلي كافٍ لتركيب دورة إيجابية كاملة لإنشاء المحاولات وتجميعها والتراجع المدقق عنها بالمحفزات الأصلية.

أكد صاحب المشروع، بعد فحص إنتاجي للقراءة فقط، وجود `nafes_scan_deletions` و`nafes_assessments` و`nafes_students` ووظيفتي `lugati_sync_sections_attempt` و`lugati_sync_student_worksheets` في الإنتاج. **العائق هو نقص التعريفات الدقيقة محليًا، وليس غياب هذه المكونات من الإنتاج.**

## ما فُحص دون إعادة الاختبارات السابقة

- جميع مرفقات المصدر والتعريفات الموجودة في `attached_assets`.
- ملفات SQL والمصدر ذات الصلة في المستودع.
- المراجع المحلية `main` و`replit-agent` و`origin/main`، دون جلب أو دفع إلى GitHub.
- أرشيف دالة Edge المرفوع، وحزمتي التطوير المحفوظتين.
- ملفات السجلات المحلية المتاحة المتعلقة بهذه التعريفات.
- بصمات ملفات حزمة مراجعة التكامل؛ هذا تحقق سلامة ملف، لا إعادة تنفيذ اختبارات النتائج.

## نتيجة إغلاق المصدر

| المكون | المصدر المتاح | النقص المحدد |
|---|---|---|
| `nafes_students` | `supabase/migrations/20260908060000_student_identity_management.sql` | تعريف تاريخي موجود، لكن لا يحتوي `is_demo` الذي يستعمله المصدر المنشور في جلب الطلاب والحفظ. لا يوجد ALTER محلي يغلق هذا الفرق؛ لا يمثل ذلك دليلًا أن العمود مفقود في الإنتاج. |
| `nafes_assessments` | `supabase/migrations/20260907130000_assessments_analytics.sql` | تعريف تاريخي يقيد `status` بـ `draft` و`published`، بينما المصدر الحالي يستخدم `archived`. لا يمكن نسب القيود والصلاحيات والمحفزات القديمة إلى المخطط المنشور الأحدث. |
| `nafes_scan_deletions` | استدعاءات وعمليات SQL في مصدر الدالة ونسخة الإصلاح | لا CREATE TABLE أو تعريف catalog كامل في المرفقات أو الأرشيفات أو المراجع المفحوصة. أسماء الحقول المستخدمة ليست تعريفًا كاملًا للجدول. |
| `lugati_sync_sections_attempt` | استدعاء داخل جسم محفز المحاولات الأصلي | جسم الدالة وتوقيعها الكامل وتبعياتها غير متاحة؛ الاستدعاء وحده لا يكفي. |
| `lugati_sync_student_worksheets` | استدعاءات داخل جسم محفز المحاولات الأصلي | جسم الدالة وتوقيعها الكامل وتبعياتها غير متاحة. |
| صلاحيات جداول المسح | تعريفات الجداول وسياسات جزئية ومنح تطويرية معلنة | لا تتوافر ACL الأصلية الكاملة اللازمة لإثبات المطابقة مع Supabase. |

ملف التعريفات المرفوع يحتوي سبعة جداول وسبع دوال للمسح، مع أجسام محفزات المحاولات، وليس تعريفات الجداول الثلاثة ووظيفتي المزامنة أعلاه. مرفق `nafes_teacher_access` مكتمل لهذا الجدول فقط.

## تجميع النتائج: أثر جانبي مهم

التعريف الأصلي المتاح لـ `nafes_teacher_attempt_page` في
`supabase/migrations/20260907143000_reporting_queries.sql` **ليس قراءة فقط**: ينفذ `UPDATE` على المحاولات المنتهية قبل جلب الصفحة. ويجمع أيضًا `nafes_exam_attempts` و`nafes_simulation_attempts` و`nafes_assessment_attempts`.

لذلك لا يجوز استدعاؤه على الإنتاج باعتباره تحققًا للقراءة فقط. لم يُستدعَ على الإنتاج، ولا يمكن اختبار آثاره الأصلية بأمان محليًا دون إغلاق تبعيات المحاولات ومحفزاتها. وجود تعريف GitHub لهذا الجزء لا يثبت مطابقته للنسخة الإنتاجية الحالية.

## ما بقي ناجحًا وما لم يُثبت

- لا تغيير في الشيفرة التنفيذية لهذه الجولة؛ بقيت نسخة مراجعة التكامل واحدة كما حُفظت سابقًا.
- الأدلة السابقة: 155 اختبارًا ناجحًا، 37 اختبار SQL مصححًا، 12 تحققًا للمصادقة والحفظ، 13 تحققًا للمتصفح، و140 ورقة اصطناعية/8400 اختيار متطابق.
- لم تُعَد تلك الاختبارات، ولم تُنسب نتائجها إلى دورة ترحيل محاولات مكتملة.
- **غير مثبت إيجابيًا:** إنشاء المحاولات مع وظيفتي المزامنة، تجميع نتائجها مع آثار المحفزات، التراجع الإداري وتأثيره على المحاولات، وتزامن هذه الدورة عبر بوابة Supabase/PostgREST الفعلية.
- بوابات التفويض واختبارات الرفض السابقة لا تعوض هذه الأدلة الناقصة.

## الحد الآمن للعمل

لم تُركب تعريفات قديمة كبديل للمخطط الحالي، ولم تُضف أعمدة أو دوال تعويضية، ولم تُعطّل محفزات. لم تُفتح مهام جديدة، ولم يُتصل بالإنتاج في هذه الجولة، ولم تتغير درجات أو سجلات طلاب أو مخطط إنتاجي، ولم يحدث نشر إلى Supabase أو GitHub Pages.

الخطوة المحجوبة المحددة هي **تركيب التعريفات الأصلية الحالية للجداول الثلاثة والدالتين وتبعياتهما وصلاحياتهما داخل البيئة المعزولة**. لا يستطيع مصدر الاستدعاءات وحده توفير هذه التعريفات.
