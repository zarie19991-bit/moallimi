# نسخة تطوير معزولة — ليست نسخة منشورة

`source` يحتوي على أحدث مصدر رفعه المستخدم من Supabase، وليس مصدر GitHub القديم.
حُفظت بنية الملفات والتبعيات الأصلية. لا يشغّل اختبار OMR نقطة دخول Edge Function،
ولا ينشئ اتصال Supabase.

التعديلات المحلية تقتصر على `omr-server.ts` و`paper-scan.ts`.
بقية الملفات الخمسة نسخ مطابقة للأرشيف الأصلي.

اختبارات `qa/omr/source.ts` تبني وحدتي المسح فقط لتعمل محليًا،
وتبني الأصل من ZIP بصورة مستقلة للمقارنة.

ممنوع نشر هذا المجلد أو استبدال مصدر الإنتاج أو GitHub القديم به تلقائيًا.
وجود اختبارات مصطنعة ناجحة لا يغني عن أوراق مسح فعلية معلّمة.
