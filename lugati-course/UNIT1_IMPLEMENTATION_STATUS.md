# حالة تنفيذ الوحدة الأولى — حقوق وواجبات

تاريخ التحقق: 2026-10-05

## النتيجة
الوحدة الأولى جاهزة **داخليًا في محرك المقرر**، لكنها لم تُدمج بعد في واجهة الطلاب المنشورة على main.

- U1-00: بوابة الوحدة.
- U1-01 إلى U1-14: 14 درسًا تعليميًا.
- U1-15: تقويم ختامي للوحدة.
- جميع U1-01..U1-15 اجتازت فحص الجاهزية الداخلي.
- 56 كتلة microlearning مخصصة لمحتوى الوحدة الأولى.
- لكل نقطة إتقان مطلوبة: 3 بدائل أسئلة على الأقل.
- التقويمات الآلية تستخدم أسئلة نهائية منفصلة عن أسئلة نقاط التعلم.
- دروس الخط والكتابة والإلقاء تنتهي بمهمة أداء وروبرك بدل الاعتماد على الاختيار من متعدد وحده.

## الدروس المبنية
1. مدخل الوحدة: وصية ذي الإصبع العدواني وقصيدة أمية بن أبي الصلت.
2. نص الاستماع: فئات تكلؤها عين الشريعة.
3. الفهم القرائي: وقضى ربك.
4. إستراتيجية القراءة: حقوق الأشخاص ذوي الإعاقة.
5. التحليل الأدبي: دَيْن الكريم.
6. الرسم الإملائي: الألف اللينة في الأفعال الثلاثية.
7. الرسم الكتابي: رسم (ل، لا) بخط الرقعة.
8. الصنف اللغوي: اسم الفاعل.
9. الأسلوب اللغوي: القسم.
10. الوظيفة النحوية: الحال.
11. إستراتيجية الكتابة: العصف الذهني وما قبل الكتابة.
12. التواصل الكتابي: كتابة خطبة محفلية.
13. التواصل الشفهي: إلقاء خطبة أمام طلاب المدرسة.
14. النص الإثرائي: حقوق المرضى ومسؤولياتهم.
15. تقويم الوحدة.

## قواعد الجاهزية
- كتلة محتوى فعلية لكل نقطة إتقان.
- 3 أسئلة بديلة على الأقل لكل نقطة.
- تقويم نهائي بعدد عناصر الدرس المحدد.
- تغطية جميع الأهداف الأساسية في التقويم الآلي.
- دروس الروبرك: تحقق معرفي للنقاط + مهمة أداء نهائية.
- 85% حد إتقان الدرس.
- 80% حد أدنى لكل هدف أساسي.
- الانتقال للدرس التالي من الخادم فقط بعد الإتقان.

## API
Edge Function `lugati-course` version 2 يضيف:
- `lesson_content`: إرجاع المحتوى المصغر للدرس دون الإجابات الصحيحة.
- readiness check يشترط الآن وجود محتوى فعلي، لا مجرد بنك أسئلة.
- الإجابات الصحيحة تبقى داخل `course_question_bank` ولا ترسل في `lesson_content` أو `start_point_check`.
